3. **在线判题**：写完后将代码复制到对应的 LeetCode 提交页提交即可，无需在本地运行或测试 `solution.py`。
4. **查看答案**：如果卡住了，打开 `README.md` 展开折叠区里的参考解法（完整可提交的 `class Solution`）。
